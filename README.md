# Bestellapp

Bestellapp is an exam project for a Frontend Web Developer Bootcamp, focusing on creating, modifying, and reading JSON data.

## Features

* JSON Data Handling – Create, read, and modify JSON data
* Dialog Elements – Use dialogs to display additional content and interactions
* Sticky Shopping Cart – Keep the shopping cart visible while scrolling
* Responsive Design – Adapt the layout to different screen sizes
* Local Storage – Save and retrieve shopping cart data using Local Storage

## Technologies

* HTML
* CSS
* JavaScript
